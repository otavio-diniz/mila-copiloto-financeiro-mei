# tests/

Casos de teste, critérios de assertividade, segurança e coerência.

## Categorias previstas

- classificação PF/PJ/PENDENTE;
- cálculos de caixa;
- projeção de compromissos e recebimentos;
- comparação de cenários de crédito;
- comportamento diante de dados ausentes;
- resistência a alucinação de números;
- clareza da explicação em linguagem simples.

Os casos definitivos serão derivados dos dados sintéticos aprovados.
