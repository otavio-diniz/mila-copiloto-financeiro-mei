# docs/

Documentação pública da MILA, separando o **caminho operacional de reprodução** do detalhamento acadêmico por etapa.

## Comece por aqui

- [`PILOT_GUIDE.md`](PILOT_GUIDE.md) — clone limpo, pré-requisitos, primeira execução, piloto funcional, validação, saídas esperadas e troubleshooting.

O README principal apresenta visão, problema, solução, estado, Quickstart e evidências em alto nível. Este diretório preserva o aprofundamento sem duplicar desnecessariamente a página principal.

- base e cenários fictícios/sintéticos;
