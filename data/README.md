# data/

Área reservada à base de conhecimento fictícia da MILA.

## Previsto para o Gate 2

- `perfil_mei.json`
- `transacoes.csv`
- `compromissos.csv`
- `propostas_credito.csv`
- `historico_interacoes.csv` (opcional, conforme decisão autoral)

## Regras

- Não usar dados bancários reais.
- Não versionar CPF/CNPJ real, credenciais ou dados pessoais sensíveis.
- Dados sintéticos devem ser claramente identificados.
- Movimentações deverão permitir as classes `PJ`, `PF` e `PENDENTE`.
- Valores, datas e cenários definitivos dependem de aprovação autoral no Gate 2.
