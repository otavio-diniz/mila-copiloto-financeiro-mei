# src/

Implementação funcional da MILA.

A stack técnica ainda não está fixada. Nenhuma dependência deve ser adicionada apenas por conveniência ou por copiar o exemplo do instrutor.

## Diretriz arquitetural

- regras e cálculos financeiros determinísticos ficam na aplicação;
- o LLM recebe apenas o contexto necessário para explicar resultados;
- valores, datas, taxas e saldos não podem ser inventados;
- dados insuficientes devem gerar solicitação de esclarecimento.

O código será criado somente após a definição autoral da base de conhecimento e dos prompts.
